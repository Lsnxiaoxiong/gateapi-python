# 网格收益实验室：成交收益与下跌持仓

本地交互式收益计算器，按每日成交次数估算交易收益，按指定下跌百分比计算最大持仓。无需 API 密钥或第三方依赖；已移除本金参数与基于本金的收益率。

## 启动

在项目根目录执行：

```powershell
python tools/grid-profit-model/serve.py
```

自动打开 http://127.0.0.1:18889/ 。可用 `--port 18890 --no-browser` 指定端口并关闭自动打开浏览器。按 Ctrl+C 停止。打开原页面后刷新即可使用新模型。

## 参数与次数口径

| 参数 | 输入单位 | 含义 |
| --- | --- | --- |
| d | 轮/天或笔/天 | 默认是每天完成的买入＋止盈轮数；选择单边成交笔数时除以 2 折算 |
| a | % | 等比例网格间隔，影响挂单价格及跌幅内持仓 |
| b | % | 相对每格买入价的止盈幅度 |
| n | USDT | 每格买入名义金额，不含手续费 |
| m | % | 单边手续费率，买入和卖出各收一次 |
| T | 天 | 计算周期 |
| P₀ | USDT | 交易对开始价格，第 0 格在此价格买入 |
| q | 张 | 交易对最小张数，按数量步长使用 |
| r | % | 从开始价格单边下跌的百分比，须小于 100%（输入最大 99.999999%） |

支持数值框和常用区间滑块。次数允许小数，代表日均成交量或配对折算量，不表示执行半笔订单。参数本地保存；旧版本迁移共用字段，舍弃本金、手动网格数量和随机价格参数，新字段使用默认值。

## 计算

百分比参数先除以 100。设日均完整买卖轮数为 k：

- 完整买卖口径：`k=d`。
- 单边成交口径：`k=d/2`，假设输入交易可完整买卖配对；未配对仓位不参与计算。
- 单轮毛收益：`n×b`。
- 单轮买入手续费：`n×m`。
- 单轮卖出手续费：`n×(1+b)×m`。
- 单轮净收益：`n×[b−m×(2+b)]`。
- 累计净收益：`k×T×n×[b−m×(2+b)]`。

默认每天 20 轮、止盈 1.2%、每格 100 USDT、单边费率 0.1%、30 天：单轮净收益 0.9988 USDT，每日净收益 19.976 USDT，累计净收益 599.28 USDT，手续费 120.72 USDT。若 20 表示单边成交笔数，则累计净收益为 299.64 USDT。

收益曲线展示累计净收益、手续费前毛收益和累计手续费；另有每日成交次数与累计收益的敏感度曲线。图例可切换曲线，指针或触摸可查看对应数值。**收益曲线仍按每格预算 n 估算**，不假设每天的成交均发生在某个特定网格；网格明细和下跌持仓则按实际数量取整，两种计算口径分别标明。

## 下跌后最大持仓

网格数量是输出，由间隔和跌幅自动计算，不再手动输入，也没有 30 格或 1000 格的持仓上限。以下公式中的百分比先除以 100：

- 自动网格数量：`K=floor[ln(1−r)/ln(1−a)]+1`。
- 最大预算持仓：`K×n`，只取决于网格间隔 a、每格仓位 n 和跌幅 r。

例如间隔 1%、每格 300 USDT、下跌 32%：`K=39`，最大预算持仓为 `39×300=11700 USDT`。包含开始价格的第 0 格；等比例网格不能直接使用 `r/a` 计算格数。

实际下单明细按用户提供的 Python 循环建格，`j=0…K−1`：

- 买价：`Pj=P₀(1−a)^j`，第 0 格为开始价格，立即买入。
- 最小一份数量的价值：`q×Pj`。
- 每格张数：`Qj=floor[n/(q×Pj)]×q`。
- 每格实际仓位：`Nj=Qj×Pj`，不超过预算 n（允许极小浮点误差）。
- 下跌后价格：`Pdrop=P₀(1−r)`。
- 触及网格：`Pj>=Pdrop`，相等时也成交。
- 实际可下单格数：触及网格中 `Qj>0` 的格数。
- 取整后的实际持仓金额：触及且可下单网格的 `Nj` 之和，按买入额统计，不是目标价的持仓市值。
- 累计张数：对应 `Qj` 之和。
- 买入手续费：取整后实际持仓金额×m。
- 买入所需金额（含费）：取整后实际持仓金额×(1+m)。

假设初始无旧仓、从开始价格单边下跌、每格最多一笔持仓、途中不反弹止盈、不限制资金。跌幅 0% 也包括第 0 格；等比例网格下跌至零需要无限格，因此拒绝 100% 跌幅。若预算不足最小一份数量，该格张数为 0，从实际持仓中排除，但不改变预算持仓。取整对恰好位于数量步长边界的极小浮点误差作修正，避免少买一份。

“最小张数”按代码中的 `min_count×price` 解释为数量步长。如交易所有额外合约面值，需先换算为此处“数量×价格”口径对应的数量步长。无杠杆、手续费以 USDT 支付，没有滑点或部分成交模型。

“使用代码示例”按钮设置开始价格 2600、间隔 0.05%、最小张数 0.001、每格预算 40、跌幅 39.33%，自动算出 1000 格。最大预算持仓 40000 USDT；实际取整后累计金额为 38967.37151777583 USDT，与原 Python 示例一致。

展开明细可查看每格买价、止盈价、跌幅、张数、实际仓位、累计实际仓位与累计预算仓位。网页最多绘制前 2000 行，超过时明确提示；这仅影响表格展示，统计和 CSV 均包含全部网格。

固定成交次数后，a 不直接进入预算收益公式，但会改变下跌情景触及的格数和取整后金额。每日成交次数不用于推导价格路径、浮亏、回撤和盈利概率；下跌持仓情景与已实现收益曲线不合并。CSV 同时导出参数、收益明细、每日曲线、下跌情景统计及逐格持仓数据。
