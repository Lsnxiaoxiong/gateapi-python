模型口径与计算说明

默认每日成交次数 d 表示完成的买卖轮数，一轮包含一次买入和一次止盈卖出。选择“单边成交笔数”时，按买卖配对假设，将输入笔数除以 2 折算为完成轮数；未配对买入不属于本模型。小数表示日均折算量，不代表可执行半笔订单。

每格买入名义金额为 n，止盈比例为 b，单边手续费率为 m。单轮毛收益=n×b，双边手续费=n×m×(2+b)，单轮净收益=n×[b−m×(2+b)]。累计净收益=日均完成轮数×天数×单轮净收益。

买价为 P₀(1−a)j，从第 0 格开始。下跌 r 后，触发格数 K=floor[ln(1−r)/ln(1−a)]+1（a、r 换算为小数）。K 为自动计算结果，最大预算持仓=K×n，不设手动格数上限。间隔 1%、下跌 32% 时 K=39，包含开始价格的第 0 格。等比例网格下跌至零需要无限格，所以跌幅须小于 100%。

设最小张数为 q，每格实际张数=floor[n/(q×买价)]×q，实际仓位=张数×买价。实际持仓为自动生成的全部触发网格逐格取整后合计。格子金额不足一份最小张数时跳过；取整计算修正极小的浮点边界误差。若交易所有额外合约面值，需先换算为此处“数量×价格”对应的数量步长。

收益曲线按每格预算 n 估算；网格明细和下跌持仓按取整后的实际金额计算。两者独立，不将下跌持仓与已实现收益合成一个账户曲线。买入所需金额含已付买入手续费，不预扣未来卖出手续费。不设置资金上限或基于本金的收益率。

只估算已实现交易收益，不含未平仓浮动盈亏、滑点、部分成交和其他成本；总账户收益仍需结合实际持仓。手续费假设以 USDT 支付，无杠杆，不连接真实交易账户。
