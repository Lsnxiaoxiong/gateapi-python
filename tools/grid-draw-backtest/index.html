Gate 网格规则与回测口径

对应本项目 auto_grid_contract_futures_generic.py / auto_grid_contract_futures_short_generic.py。多头价位为参考价 × (1 − 间隔)^索引，空头为参考价 × (1 + 间隔)^索引；索引可为负，无固定价格上下限。只维护现价下方最近 N 个多头买格或上方最近 N 个开空格，区间外开仓单撤销；已开仓保留且同入场价不重复开仓。

止盈独立于网格间隔。多头：入场价 × (1 + 止盈比例) 向上对齐价格步长；空头：入场价 × (1 − 止盈比例) 向下对齐。仅在止盈检查窗口内维护最靠近现价的指定数量止盈单；超窗撤单保留仓位，回到窗口后再挂。初始无底仓，不在参考价直接开仓。

保证金 × 杠杆换算名义金额，再按合约面值和张数步长向下取整。规格采用离线示例，须按目标合约填写。回测资金用于模拟可用保证金，资金不足暂停新增开仓，已有仓位和止盈继续维护。

手绘 JSON 使用逐像素路径，普通 OHLC 按所选高低顺序模拟；跳空按穿越顺序以限价成交。采用路径上的即时挂撤单模型，不复刻实盘轮询间隔、网络延迟、SQLite 恢复、部分成交和外部手动平仓。不模拟强平、滑点或资金费率，未扣未来平仓费。净值 = 回测资金 + 已实现净收益 + 持仓浮动净收益，回撤按路径时点及成交统计。

每个策略独立资金，不共用保证金。最多 12 个策略，每策略活动开仓格数及止盈单各最多 300，止盈检查范围最多 1000 格；活动窗口不限制累计持仓数。行情最多 200,000 根。每策略仅保留最近约 10,000 笔成交日志，完整累计指标不受影响；导出会注明日志是否截断。
