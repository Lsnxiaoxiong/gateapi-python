# Grid Canvas：手绘行情与多网格动态回测

独立本地程序，使用 Python 标准库启动，浏览器完成所有绘图与计算。无需安装前端依赖、构建或填写 API 密钥，不连接交易所。

## 启动

Windows 可直接双击本目录的 `launch.cmd`，自动启动并打开浏览器（需要已安装 Python）。

在项目根目录运行：

```powershell
python tools/grid-draw-backtest/serve.py
```

自动打开 <http://127.0.0.1:18890/>。指定其他端口或关闭自动打开：

```powershell
python tools/grid-draw-backtest/serve.py --port 18891 --no-browser
```

按 Ctrl+C 停止服务。

## 手绘行情

1. 在「绘制行情」中按住鼠标、触控笔或触屏，从左到右绘制趋势。笔尖靠近左、右、上、下边缘时，画布自动向对应方向延伸并跟随移动；停留在边缘可持续延伸，角落可同时向两个方向扩展，松开即停止。支持分段绘制、多笔叠加、画笔粗细、撤销、清空以及三种示例走势。
2. 设置起始价格、每像素幅度、每根 K 线包含的像素列数、周期与开始时间。K 线预览随之更新。
3. 点击「保存行情并用于回测」，或导出 JSON / CSV。资料库支持再次导出、选择、删除与导入。

画布采用可向四周延展的世界坐标，初始视野为 **1200 × 400 逻辑像素**。移动视野只改变查看位置，不缩放或移动原笔迹，也不改变每像素的价格幅度。只为画过的区域分配小块透明图层，并增量更新列均值，避免随着画布扩大而重复扫描整张大图。窗口缩放或高分屏不会改变采样精度。网格、背景与平均线不参与统计。每列对所有 alpha > 0 的笔迹像素取纵坐标的算术平均值，包含抗锯齿边缘，每个像素等权；多笔重叠像素仅统计一次。

滚轮移动视野，Shift + 滚轮水平移动；也可按住空格加左键拖动，或使用鼠标中键拖动。点击「起点」回到初始视野，保留全部笔迹。撤销会移除上一整笔，包括自动延伸部分；清空会同时重置视野。JSON 的 `mapping` 记录实际采样宽度及世界坐标原点。单段手绘最多 200,000 列像素，超过会提示分段保存。

`P(x) = P₀ + [ȳ(0) − ȳ(x)] × 每像素幅度`。

向上为上涨。起始采样列取原点与最左笔迹横坐标的较小值，右侧以最右笔迹为止，向左画到负坐标时同步扩展采样起点。左侧空白延用最左笔迹均值，使数据第 0 列始终对应起始价格。笔迹间空白线性插值；最后笔迹之后不补尾。仅移动视野不会增加 K 线或改变价格。拒绝空画布、单列笔迹和小于等于零的价格。

每组像素生成一根 K 线：开盘为上一根收盘（第一根为起始价格），最高/最低包含开盘和组内像素价格，收盘为本组最后像素价格。最后不足一组仍保留。成交量为 0。**JSON 保留每根 K 线的 `path`，可以精确重放原手绘波动；CSV 仅保存 OHLC，重新导入后使用模拟路径。**

## Gate 合约网格回测

配置与计算规则对应仓库当前的 `example/auto_grid_contract_futures_generic.py`、`example/auto_grid_contract_futures_short_generic.py`，以及它们复用的 `auto_grid_futures_generic.py` 价格函数、单格单周期及止盈窗口规则。支持同时回测最多 12 个独立策略，可以做多和做空混用，分别设置名称、颜色、开关、复制或删除。

| 界面配置 | 脚本参数 / 合约字段 | 含义 |
| --- | --- | --- |
| 参考价 | `reference_price` | 固定锚点；界面额外支持 0，取第一根开盘价 |
| 每格保证金 | `margin_amount_per_order` | 单格保证金预算，USDT |
| 杠杆 | `leverage` | 用于换算名义仓位及实际保证金 |
| 网格间隔比例 | `grid_step_pct` | **输入比例原值**，如 `0.00042 = 0.042%` |
| 独立止盈比例 | `take_profit_pct` | 与网格间隔分开设置，单位同上 |
| 活动开仓格数 | 多头 `buy_grid_count` / 空头 `short_grid_count` | 维护现价下方买单或上方开空单的滚动窗口 |
| 活动止盈单上限 | `take_profit_count` | 距现价最近的活动平仓单数量上限 |
| 止盈检查范围 | `take_profit_grid_count` | 止盈窗口的网格跨度，独立于止盈单上限 |
| 每张面值 | `quanto_multiplier` | 每张合约对应的标的数量 |
| 价格步长 | `order_price_round` | 锚定网格四舍五入，止盈按方向取整 |
| 张数步长 / 最小张数 / 最大张数 | 合约下单精度与限制 | 张数向下取整；最大值 0 表示回测不设此限制 |
| 回测资金 / 单边手续费 | 回测账户参数 | 各策略独立计算保证金、净值和双边手续费 |

默认保证金 2.7、杠杆 3、活动开仓 20、止盈单 20、止盈检查 30、网格间隔和止盈比例均为 0.00042，取自当前 `example/grid_contract_ETH.py`。默认参考价为自动起价。**合约规格为离线示例，不是自动读取的 ETH/BTC 真实规格**，请在「合约规格与回测资金」中按目标合约填写；不访问交易所或账户。

- 多头锚定价格 `Pᵢ = reference × (1 − grid_step_pct)^i`；空头为 `reference × (1 + grid_step_pct)^i`，按价格步长 `ROUND_HALF_UP`。索引可为负，没有固定价格上下限。取整后相同价格跳过重复。
- 多头仅维护**严格低于**现价的最近 N 个买格；空头维护**严格高于**现价的最近 N 个开空格。窗口外的未成交开仓单撤销。初始无底仓，不在参考价直接开仓。
- 每个取整后的入场价最多一个活动周期，包含待开仓或已开仓未平仓；旧仓即使离开窗口仍占用该格，不重复开仓。活动窗口数量不是累计持仓上限。
- 多头止盈价 `入场价 × (1 + take_profit_pct)` 向上取整；空头止盈价 `入场价 × (1 − take_profit_pct)` 向下取整。平仓单带 `reduceOnly=true`，数量使用原开仓张数。
- 多头止盈窗口为 `(现价, 上界]`，空头为 `[下界, 现价)`。边界使用脚本相同的 `firstIndex − take_profit_grid_count` 计算，按距现价最近排序保留最多 `take_profit_count` 单。窗口外止盈单撤销但仓位保留，重新进入窗口再挂；没有活动止盈单时不虚报成交。
- 张数 = `每格保证金 × 杠杆 ÷ (开仓价 × 每张面值)`，向下对齐张数步长；实际保证金 = `张数 × 面值 × 开仓价 ÷ 杠杆`。小于最小张数或超过最大张数会报错。资金预留包括实际保证金及预期开仓费，不足时停止本轮新增开仓，已有止盈继续维护。
- 支持开始、暂停、继续、单步、重置和运行到最后，速度 2 / 10 / 50 / 200 根每秒。修改计算参数或切换数据会清空回测，调整颜色保留进度。后台标签页自动暂停。
- 图中实线为开仓、虚线为止盈；策略横线按颜色分列，同价也可辨认。▲ 为买入、▼ 为卖出。未来 K 线暗色显示，竖线为进度。悬停查看原始 OHLC。
- 展示净收益、浮亏、保证金占用、可用与预留资金、持仓与待挂止盈数、回撤、挂单和成交。报告 JSON 包含模型版本、完整策略参数、实际参考价、净值序列和成交明细；CSV 区分多空、开平、张数与标的数量。
- 旧固定区间策略会显式迁移，保留名称、颜色、开关、资金和费率，旧每格金额按新杠杆换算保证金；原配置保存在 `legacyConfiguration`，随回测报告导出。由于固定区间没有等价滚动参数，间隔和窗口采用新默认值并提示重新确认。行情资料保持不变。

## 数据导入与保存

CSV：`time,open,high,low,close,volume`，volume 可省略；支持标准 Binance 无表头列序及带 `open_time` 等时间列名的表头。数据行的字段不应包含嵌入逗号或换行。JSON 支持 K 线对象数组或包含 `candles` 数组的对象。时间支持 Unix 秒、毫秒或 ISO 字符串；建议文本时间包含时区。价格、OHLC 边界、路径一致性和时间严格递增均会校验。

策略配置与较小的行情存到当前浏览器的 localStorage（同域名、同端口）。持久化总字符数限制约 150 万，超出时明确提示只存当前会话，务必自行导出 JSON。单文件最多 32 MB、200,000 根 K 线，每个策略活动开仓单和止盈单各最多 300，止盈检查跨度最多 1000 格，不设固定累计持仓格数。切换浏览器或端口不共享资料库。清理浏览器数据会删除本地保存内容。

## 撮合口径与限制

- 手绘 JSON 使用原始逐像素路径，支持同一根 K 线内多次完整买卖；普通 OHLC 按「开→低→高→收」或「开→高→低→收」逐段模拟。两种假设可能产生不同结果，界面显示当前口径。混合数据的已有 path 优先，缺少的采用所选模式。
- 按价格路径穿越顺序撮合，在锚定网格边界及成交时即时维护窗口。活动开仓或止盈单触价才成交，未挂出的止盈不会补记历史成交。跨 K 线开盘跳空仍按穿越顺序以限价模拟，并即时滚动窗口，不给予跳空价格改善。所有成交记在所属 K 线起始时间，没有逐笔真实时间信息。
- 总盈亏 = 已实现净收益 + 未平仓浮动净收益；钱包余额只扣已付手续费及加减平仓毛盈亏，不按现货买入扣掉整笔名义金额。净值 = 钱包余额 + 持仓毛浮动盈亏。保证金占用和开仓预留分别统计。未平仓浮动净收益含该仓位已付开仓费，未来平仓费尚未预扣。回撤为净值历史高点至低点的金额，在路径点、网格边界和成交时点统计。
- 本地只复刻确定性的网格交易规则：不重现实盘的 REST / WebSocket 轮询时延、SQLite 恢复、外部手动平仓、网络失败与重试、碎片仓、盘口队列、部分成交、滑点、成交量限制、资金费率或强平。杠杆已用于仓位和保证金换算，但负可用保证金不会触发强平；需要结合此口径理解结果。
- 若行情运行过程中保证金预算不足最小下单张数等错误导致中断，界面停止并要求重置或修改配置，避免重复执行同一根 K 线。中断报告的 `failed=true`，已处理根数不包含出错根，统计可能包含出错根内已执行的部分路径。
- 图表超过 600 根会聚合显示，撮合始终使用全部原始数据。界面最近成交显示 100 笔；每策略内存日志保留最近约 10,000 笔，超出时删除最旧 1,000 笔，**完整累计盈亏和成交计数不受影响**。导出报告含 `tradesTruncated`；超出上限的成交 CSV 导出会提示。

## 验证

```powershell
node --test tools/grid-draw-backtest/test-model.cjs tools/grid-draw-backtest/test-drawing.cjs tools/grid-draw-backtest/test-grid.cjs
```

覆盖像素均值、起始锚点、插值与 K 线分组，CSV/JSON 往返、数据校验，以及 Gate 多空方向、严格开仓边界、负索引、滚动撤单、独立止盈、窗口名额、旧仓回窗、单格单周期、合约面值与精度、保证金不足、手续费、长序列净值守恒和旧配置迁移。

`test-grid.cjs` 会通过 Python 标准库运行 `verify-gate-parity.py`，后者仅从当前仓库脚本的 AST 提取白名单纯函数，**不导入或执行交易入口、不读取密钥、不联网**。多空共 12 组情景逐项对比开仓价、止盈价、窗口边界及张数，另校验默认参数与当前 ETH 包装脚本一致。

自动扩展的方向、边缘速度、坐标换算与缩放精度由 `test-drawing.cjs` 验证。启动服务后打开 <http://127.0.0.1:18890/test-drawing-browser.html> 运行浏览器光栅回归检查：跨图块接缝、负坐标、多笔重叠及增量均值逐列与实际笔迹的整图扫描结果比较，另验证视野移动不改变采样、生成 K 线和清空行为。
